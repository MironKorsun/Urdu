# Шер Урду — урду как в Duolingo

**Открыть:** https://mironkorsun.github.io/Urdu/

Мобильное веб-приложение для изучения урду с нуля: от «Салам» и «Мучхе тумсе мохаббат хай» до послелогов
и притяжательного **کا / کی / کے** (аналог родительного падежа). Дизайн — бордовый лак и золото.

## Что внутри

- **Путь** — 6 разделов уроков в стиле Duolingo: приветствия, местоимения, «я тебя люблю», числа и семья,
  کا / کی / کے, послелоги (میں, پر, سے, کو). Упражнения: карточки, выбор перевода, пары, сборка фразы из слов,
  вставка пропущенного слова, правила грамматики, обводка слов. Серия дней, опыт и сердечки.
- **Алфавит** — 39 букв: звук, соединяемость, слово-пример, озвучка.
- **Письмо** — тренажёр письма пальцем: **насталик** и **насх** в отдельных режимах, «по контуру» и «по памяти»,
  оценка похожести и звёзды.
- Переключатель насталик / насх в шапке меняет шрифт урду во всём приложении.

## Установка на телефон

Откройте ссылку в браузере телефона:
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

Приложение откроется во весь экран со своей иконкой и будет работать без интернета после первого захода.
Прогресс хранится в браузере на устройстве (localStorage).

## Устройство

Один файл `index.html` (HTML + CSS + JavaScript без библиотек), `manifest.webmanifest`, офлайн-кэш `sw.js`, иконки в `icons/`.
Шрифты: Noto Nastaliq Urdu, Noto Naskh Arabic (Google Fonts). Озвучка — синтез речи браузера (голос ur-PK, если установлен).
Сайт публикуется GitHub Pages из ветки `main`, каждый `git push` обновляет его за минуту.
